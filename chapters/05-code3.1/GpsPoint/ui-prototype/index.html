GPS 定点 · UI 原型（简化版）

只做一件事：提前用手机采一个真实定位点，需要时一键把手机定位定到那儿。 一个界面、一个主按钮、一份点位列表。没有地图、没有路线、没有轨迹回放、没有倍速。

只有一个界面

点位列表就是主界面，没有第二个 Activity、没有 tab、没有抽屉、没有设置页。

主按钮位置固定：空闲＝记录当前位置，定位中＝停止定位。只有文案和颜色变，几何尺寸不变。

两种操作，互斥

采集：读手机真实 GPS，存成本地点位。应用：把假坐标写进系统定位。

注入会注册名为 gps 的测试 Provider 顶掉真实 GPS，此时采集只会采到假坐标 —— 所以定位中隐藏采集入口，先停再采。

刻意不做

地图、选点画布、路线规划、轨迹录制与回放、倍速、摇杆、GPX、云同步、账号、分享、设置页。

列表行只放三样：名字、经纬度、精度与采集时间。不放大段说明、不放插图。
