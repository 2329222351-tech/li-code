# GPS 定点 · UI 设计（简化版）

> 一句话：**提前用手机采一个真实点位，需要时一键把手机定位定到那儿。**
> 一个界面、一份列表、一个主按钮。没有地图、没有路线、没有轨迹回放、没有倍速。

高保真原型：[`ui-prototype/index.html`](ui-prototype/index.html) · 整页截图：[`ui-prototype/ui-design.png`](ui-prototype/ui-design.png)

---

## 一、设计原则（"简化"的落地标准）

1. **只有一个界面。** 没有第二个 Activity、没有 tab、没有抽屉、没有设置页。
2. **主按钮只有一个，位置永久固定。** 空闲＝记录当前位置，定位中＝停止定位；只换文案和颜色，尺寸与位置不动，闭着眼也能按准。
3. **列表就是主界面。** 点一行 = 立刻定位过去；长按一行才出现改名/删除。
4. **不用的东西直接隐藏，不置灰。** 权限条只在缺权限时出现；空库时列表位置换成一句话。
5. **不弹确认的就不弹。** 点行应用不弹确认；只有删除要二次确认。
6. **一屏装得下。** 列表滚动，其余元素不滚动。
7. **每个屏幕只有一种主色。** 定位中＝蓝，停止＝红，其余全是墨色灰阶。

## 二、界面结构（自上而下）

| 区域 | 内容 | 何时出现 |
|---|---|---|
| 顶栏 | `GPS 定点` + 右侧「N 个点位」 | 常驻 |
| 状态名 | 26sp 加粗：`空闲` / `定位中` | 常驻 |
| 状态行 | 等宽字体，一行：`未应用 · 点一行即可定位` / `公司 · 30.274149, 120.155030 · ±6 m` | 常驻 |
| 权限条 | 一行字 + 「去设置」 | **只在缺权限时出现** |
| 分组标题 | `点位` + 右侧提示「长按改名 / 删除」 | 常驻 |
| 列表 | 每行：名字 / 经纬度 / 精度 · 采集时间 | 点位数 > 0 |
| 空态 | 图钉 + 「先采一个点位」+ 两行说明 | 点位数 = 0 |
| 主按钮 | 58dp 高、14dp 圆角 | 常驻 |
| 脚注 | 一行 11sp 提示 | 常驻 |

### 列表行（唯一一种卡片）

```
┌──────────────────────────────────────┐
│ 公司                                 │  ← 16sp 600，使用中变主色
│ 30.274149, 120.155030                │  ← 12sp 等宽，次要色
│ 精度 ±6 m · 09-24 09:12 采集          │  ← 11sp 三级灰
│                            使用中 / › │  ← 使用中＝蓝色胶囊，否则细箭头
└──────────────────────────────────────┘
```

- 整行可点（热区远大于 48dp），整行可长按。
- 使用中的行：淡主色底 `#EDF3FA` + 主色描边 + 右侧「使用中」胶囊，去掉箭头。
- 行与行间距 9dp，用 item 自身底部 padding 实现，不用 divider。

## 三、状态表（全部状态，只有三种）

| 状态 | 状态名 | 状态行 | 主按钮 | 列表 |
|---|---|---|---|---|
| 空闲 · 无点位 | 空闲（墨） | 还没有点位 | ＋ 记录当前位置（蓝） | 空态 |
| 空闲 · 有点位 | 空闲（墨） | 未应用 · 点一行即可定位 | ＋ 记录当前位置（蓝） | 可点 |
| 采集中 | 空闲（墨） | 正在取定位… ±精度 | 记录当前位置（禁用） | 可点（点了只提示） |
| 定位中 | 定位中（蓝） | 名字 · 坐标 · ±精度 | 停止定位（红） | 使用中高亮，点其他行＝切换 |

> 只有三种**视觉状态**：空闲 / 采集中 / 定位中。上一版 GpsRoam 的「录制中 / 回放中 / 已暂停 / 已选轨迹」全部不需要了。

## 四、交互规则

### 1. 采集（用手机提前定位）

1. 点主按钮「＋ 记录当前位置」→ 按钮立即禁用，状态行变「正在取定位…」，脚注说明「最长等 15 秒」。
2. **取最好的一次 fix**：状态行实时显示当前精度（`正在取定位… ±23 m`）。
   - 精度好到 `±12 m` 立刻收；
   - 否则再听 3 秒，取这段时间里最好的一次；
   - 全程 15 秒仍没有 ≤100 m 的 fix → 失败提示，宁可报错也不存一个偏几百米的点。
3. 取到 fix → 弹「保存点位」：
   - 输入框预填 `点位 09-24 15:32`，可以直接保存；
   - 对话框正文显示 `30.274149, 120.155030 · 精度 ±6 m`。
4. 保存 → 轻提示「已保存：公司」，列表刷新，新点排最前。
5. 拿不到定位 → 轻提示「没收到定位，到空旷处再试」，**不拿系统缓存坐标凑数**。

### 2. 应用（需要时使用）

1. 点列表中的某一行 → **立刻**开始定位，不弹确认。
2. 若未授权「模拟位置」→ 提示 + 直接跳开发者选项。
3. 若缺「精确定位」权限 → 提示 + 系统权限弹窗。
4. 定位中再点其他行 = **切换点位**：Provider 不拆不建、心跳不断，只换坐标，不会闪回真实位置。轻提示「已切换到 家」。
5. 停止：点主按钮「停止定位」，或通知栏的「停止」。

### 3. 长按

- 只给两个动作：**重命名** / **删除点位**。
- 删除需二次确认（「删掉就找不回来了。」）；删的是正在使用的点会先自动停止注入。
- 重命名时若正在用这个点，通知栏与状态行同步更新。

### 4. 采集与定位互斥（硬性）

注入会注册名为 `gps` 的测试 Provider 顶掉真实 GPS。此时去采集，采到的就是我们自己写进去的假坐标。
所以：**定位中不出现采集入口**（主按钮变成停止）；采集过程中点列表只提示「正在采集定位，稍等一下」。

### 5. 权限条

- 两项权限：`ACCESS_FINE_LOCATION`（精确定位，采集/定位都需要）、「模拟位置」授权（开发者选项里选本应用）。
- 齐了就整条隐藏。文案分三种：只缺定位 / 只缺模拟位置 / 两个都缺。
- 按钮「去设置」：缺定位先弹权限；否则跳开发者选项。
  开发者选项还没打开时，直接送到「关于手机」并提示连点版本号 7 次
  （否则系统那个页面只会弹「不可用」再退回，用户会以为按钮坏了）。

### 6. 转屏

- 这是**手机上的单屏工具，锁定竖屏**（`screenOrientation="portrait"`）。
  横屏下这套「状态 + 列表 + 大按钮」会挤成一团，不如不做。
- 同时声明 `configChanges="orientation|screenSize|screenLayout|keyboardHidden"`：
  分屏/折叠屏改尺寸时不重建 Activity，正在采集的定位和命名对话框都不会被打断。

## 五、视觉规范

| 令牌 | 值 | 用在哪 |
|---|---|---|
| 主色 `brand` | `#185FA5` | 定位中状态名、使用中行、主按钮 |
| 主色深 `brand_dark` | `#0C447C` | 主题 colorPrimaryDark |
| 主色淡 `brand_weak` | `#EDF3FA` | 使用中行的底 |
| 停止红 `stop` | `#A32D2D` | 停止定位按钮 |
| 墨色 `ink` | `#2C2C2A` | 标题、状态名（空闲）、名字 |
| 次要 `ink2` | `#5F5E5A` | 状态行、坐标 |
| 三级 `ink3` | `#888780` | meta、分组标题、计数 |
| 四级 `ink4` | `#B4B2A9` | 提示、箭头、空态图钉 |
| 描边 `line` | `#E7E9EE` | 卡片描边 |
| 警告底 / 字 | `#FAEEDA` / `#633806` | 权限条 |

- **字体**：正文用系统字体；所有坐标与状态行用**等宽字体**，数字跳动时不左右抖。
- **尺寸**：标题 17sp / 状态名 26sp / 名字 16sp / 坐标 12sp / meta 11sp / 主按钮 17sp。
- **圆角**：卡片 14dp、主按钮 14dp、权限条 10dp、胶囊 99dp。
- **间距**：页边距 20dp；状态区距顶 16dp；分组标题距上 22dp；主按钮距上 16dp。
- **主按钮**：58dp 高，唯一的大色块，永远贴着底部。
- **无地图、无图片素材**，图标只有两个：线描图钉（空态）、通知栏小图钉。

## 六、明确不做（本版砍掉）

| 砍掉 | 原因 |
|---|---|
| 地图 / 地图选点 | 需求只是「一个具体点位」，接图就要 Key + 坐标系转换 |
| 路线规划、直线移动、摇杆 | 只要定点 |
| 轨迹录制 / 回放 / 倍速 | 那是上一版 GpsRoam 的主线，与本版无关 |
| 点位搜索、分组、排序 | 点位最多几十个，按采集时间倒序就够 |
| 手动输入经纬度 | 「提前用手机定位」即可覆盖；真需要再加一行输入框 |
| 复制坐标 / 分享 | 坐标只给系统定位用，不是用来传播的 |
| 设置页、引导页、主题切换 | 没有值得设的东西；权限提示已经说明一切 |
| 账号 / 云同步 / 统计 | 不联网，没有 INTERNET 权限 |

## 七、原型与实现的对应

| 原型文件 | 实现 |
|---|---|
| `ui-prototype/index.html` 六屏 | `app/src/main/res/layout/activity_main.xml` + `item_point.xml` + 两个 AlertDialog |
| 色板 / 字号 | `res/values/colors.xml`、`themes.xml`、各 layout |
| 文案 | `res/values/strings.xml` |
| 状态切换 | `MainActivity.render()` |
| 主按钮两种形态 | `render()` 里 `R.string.btn_capture` / `R.string.btn_stop` + `R.color.brand` / `R.color.stop` |
| 使用中行 | `PointAdapter.getView()` 切 `bg_point_row` / `bg_point_row_active` |
| 权限条 | `MainActivity.renderPermission()` |

原型是 HTML/CSS 画的手机框，**不是** App 截图；模拟器实拍见 [`screenshots/`](screenshots)。
