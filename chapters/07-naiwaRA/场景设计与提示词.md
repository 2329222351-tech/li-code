## 1. 三大铁律

1. **可爱是皮，怪诞是骨**：奶白、粉红、奶牛纹这些"可爱"元素必须长在**肮脏、狭窄、废弃**的工业环境里。反差就是 itch 味。
2. **色彩要"脏"**：白色偏黄绿，粉色偏灰，避免干净纯色。像放了几年的奶渍。
3. **看不远**：浓雾 + 短可视距离。恐怖来自"看不清的尽头"，不是血。

补充两条 v2 新增：

4. **每个场景都必须有一处"笑点物件"**——拖鞋、标语、鸽子、涂鸦。没有笑点的场景就不是这个游戏。
5. **每个场景都必须有一处"恐怖物件"**——雾中轮廓、雪花屏、笑脸墙、滴答声。两种情绪同框。

## 5. 渲染管线（这是"PS1 味"的技术根）

完整链路，按顺序：

```
场景几何体（低面数 + flatShading）
  ↓
顶点抖动 shader（量化坐标，模拟 PS1 浮点误差）
  ↓
渲染到 320×240 RenderTarget（NearestFilter）
  ↓
色阶 + Dither fragment shader
  ↓
扫描线 / CRT 暗角
  ↓
放大到画布（image-rendering: pixelated）
```

**基础 RenderTarget**

```js
const rt = new THREE.WebGLRenderTarget(320, 240, {
  minFilter: THREE.NearestFilter,
  magFilter: THREE.NearestFilter,
  depthBuffer: true
});
// CSS: canvas { image-rendering: pixelated; width:100%; }
```

**顶点抖动（挂在所有场景材质上）**

```glsl
// vertex
uniform float uJitter; // 建议 0.5 / 320
vec4 mv = modelViewMatrix * vec4(position, 1.0);
mv.xy = floor(mv.xy / uJitter + 0.5) * uJitter;  // 屏幕空间量化
gl_Position = projectionMatrix * mv;
```

**色阶 + Dither（后处理 pass）**

```glsl
// fragment
uniform sampler2D tDiffuse;
uniform vec2 uResolution;   // (320, 240)
varying vec2 vUv;
void main() {
  vec3 c = texture2D(tDiffuse, vUv).rgb;
  c = floor(c * 6.0 + 0.5) / 6.0;              // 6 级色阶
  float bayer = mod(floor(vUv.x * uResolution.x) +
                    floor(vUv.y * uResolution.y) * 2.0, 4.0) / 16.0;
  c += (bayer - 0.125) * 0.04;                  // 4x4 Bayer 抖动
  float scan = 0.94 + 0.06 * sin(vUv.y * uResolution.y * 3.14159);
  c *= scan;                                     // 扫描线
  gl_FragColor = vec4(c, 1.0);
}
```

**雾**：`THREE.FogExp2(color, density)`，密度按上表。远景直接被雾吃掉，省建模。

**面数预算**：奶蛙 300–600 三角面；怪物 ≤200；场景道具单件 ≤100；全场景目标 < 15k 三角面。

## 2.1 传送带醒来处 · 完整规格

**叙事定位**
开场场景。玩家在这里得知自己身份（第 13 号试饮员），完成移动/手电/装死教学。情绪目标：懵 → 不安 → "这地方不对劲"。

# 第七部分 · 场景连贯性规则

让 12 个场景看起来像同一个游戏，靠这些母题复现：

1. **奶牛纹母题**：每个场景至少出现一处奶牛纹（海报、雨衣、售货机贴纸、标签），但每次形态不同、都在褪色。
2. **吊牌复现**："NO.13"吊牌在开场、监控室、结局画面各出现一次，像签名。
3. **奶渍渐变**：从醒奶区的"白色奶渍" → 发酵区的"发黄黏液" → 主奶泵室的"粉色母液"。玩家走进得越深，奶的颜色越不对劲。
4. **笑点物件分级**：小笑点（标语、袜子、马克杯）→ 中笑点（鸽子、价目表、录音机）→ 大笑点（笑脸墙、奶盒蜡烛、评分界面）。密度随幕递增。
5. **光照逻辑**：越往里，光源越"活"——荧光灯闪（机械）→ 吊灯摇（不稳定）→ 母液罐搏动（像心脏）。工厂本身越来越像一个活物。
