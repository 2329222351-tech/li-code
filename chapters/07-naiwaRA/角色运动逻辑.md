# 角色运动逻辑 · CHAR_MOTION v1

> 独立动效层，**未改动 index.html、未加入主场景**。
> 只改部件的 position / rotation / scale；不碰材质、碰撞、交互、剧情判定。
> 状态由外部功能层通过 `ctx.state` 驱动，本模块只负责"在这个状态下角色怎么动"。

| 文件 | 作用 |


## 接入方式

```js
// 加载 GLB 后创建运动控制器
const m = CharMotion.create('spider', gltf.scene);

// 每帧调用（t 累计秒，dt 帧间隔秒）
m.update(t, dt, {
  state: 'chase',          // 状态名，见下表
  player: camera.position, // THREE.Vector3，眼睛/身体追踪目标
  speed: 0.8               // 0~1，影响步态快慢
});
```

`update` 内部每帧从部件基准姿态重算，不会逐帧累积漂移；状态切换有 0.4 秒淡入。

## 通用子运动（模块内部复用）

| 子运动 | 效果 |
|---|---|
| `breath` | 缩放起伏，呼吸 |
| `bob` | 上下浮动 |
| `sway` | 左右摇摆 |
| `jitter` | 高频小幅痉挛（恐怖抖动） |
| `drips` | 黏液拉长→滴落复位循环，各滴错相 |
| `blink` | 周期眨眼 |
| `gaze` | 瞳孔朝目标局部偏转 |
| `offsetAll` | 整组位移（降临/飞走/离开） |

### 蛙神 `frogGod`
| 状态 | 动作 |
|---|---|
| idle | 缓慢呼吸、身体轻微起伏，云披风各块错相翻涌，王冠轻晃 |

| speak | 低头看你、嘴巴张大、眼睛亮起 |

| 状态 | 动作 |
|---|---|

|---|---|

## 边界说明

- 本模块**不决定**什么时候切换状态——那是功能层（剧情/AI/判定）的事。外部传入 `ctx.state` 即可。
- `ctx.player` 只用于视觉追踪（眼睛、身体朝向），不参与任何碰撞或命中判定。
- 演示页里的脏色材质是按部件名映射的近似配色，仅用于脱离主场景时预览；游戏内请以 index.html 的 PS1 管线为准。
