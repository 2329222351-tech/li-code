# MagicOS 10 后台白名单配置手册

> 核心目的：让 AutoX.js 和 Tasker **后台不被杀**，否则定时触发根本不靠谱。

---

## ⚠️ MagicOS 10 是出了名的杀后台严

荣耀继承了华为 EMUI 的血统，后台管理严格。光装上 AutoX.js 和 Tasker 不够，**必须**完成下面 6 个白名单设置，否则定时任务会被系统秒掉。

---

## 第 1 步：装两个 APP

### AutoX.js（自动化执行）

**重要**：原 `kkevsek/autoX` 仓库已被作者删除，当前活跃 fork 是 **`yuezy3/AutoX`**。

GitHub 仓库：https://github.com/yuezy3/AutoX

下载方式（按推荐度排序）：

1. **GitHub Release 页面下载 universal APK**（推荐）
   - 打开 https://github.com/yuezy3/AutoX/releases
   - 下载 `app-universal-release.apk`（最大兼容，~100MB）
   - 如果 GitHub 慢，用 https://toolwa.com/github/ 加速链接下载

2. **arm64 真机专用**（如果 universal 太大）
   - `app-arm64-v8a-release.apk`（~30MB）

3. **国内备用下载源**（如果 GitHub 死活下不下来）
   - 脚本之家：https://www.jb51.net/softs/523496.html （v7.2.1）
   - 雷电/夜神应用商店里搜"AutoX.js"（模拟器里方便）

### Tasker（定时调度）

- Google Play（需要谷歌框架）
- 或者国内第三方市场（华为应用市场/百度/搜到的"Tasker 安卓"）
- 价格：Google Play 约 ¥30，国产免费版可能功能受限

## 第 2 步：基础权限

### 2.1 AutoX.js 权限

1. 打开 AutoX.js
2. 会弹权限申请，全部**允许**：
   - 文件 / 媒体访问
   - 通知
   - **无障碍服务**（最重要！）
     - 跳到系统设置 → 找到 AutoX.js → 开启"无障碍"
3. 左上角菜单 → **"前台服务"** → 启动（保活用）

### 2.2 Tasker 权限

1. 打开 Tasker
2. 同样弹权限申请，全部允许
3. 关键权限：
   - 通知
   - 电池白名单
   - 开机自启（后面会单独配）

## 第 3 步：MagicOS 10 后台白名单（核心 6 件事）

> **路径在 MagicOS 10 上大致是**：设置 → 电池 → 应用启动管理

### ✅ 3.1 启动管理（最重要）

```
设置 → 电池 → 应用启动管理
   → 找到 AutoX.js → 三个开关全部打开：
       ✓ 自动启动
       ✓ 关联启动
       ✓ 后台运行
   → 找到 Tasker → 同样全部打开
```

**如果不打开这一项，定时器根本触发不了。**

### ✅ 3.2 电池优化

```
设置 → 电池 → 更多电池设置
   → 找到"电池优化"或"省电策略"
   → 切换到"所有应用"
   → 找到 AutoX.js → 选"不优化"或"允许后台运行"
   → 找到 Tasker → 同样选"不优化"
```

### ✅ 3.3 应用锁 / 多任务卡片锁定

每次你从最近任务清理的时候，快手极速版和 AutoX.js/Tasker 会被一起杀掉。

**多任务锁定**：
- 上滑打开多任务卡片
- 长按 AutoX.js 卡片 → 选"锁定"
- 长按 Tasker 卡片 → 选"锁定"
- 现在清理的时候这两个不会被杀

### ✅ 3.4 通知权限

```
设置 → 通知 → 应用通知管理
   → 找到 AutoX.js → 全部允许
   → 找到 Tasker → 全部允许
```

（否则脚本完成后你看不到通知）

### ✅ 3.5 自启动

```
设置 → 应用 → 应用管理 → AutoX.js
   → 拉到最下面 → 看"自启动"开关
   → 打开
（Tasker 同理）
```

### ✅ 3.6 后台耗电详情

```
设置 → 电池 → 耗电详情
   → 看看 AutoX.js / Tasker 有没有"被限制后台活动"
   → 如果显示"高耗电已限制" → 点击 → 选"允许"
```

## 第 4 步：测试 AutoX.js 是否跑得通

1. 打开 AutoX.js
2. 点"+" → 写个最简单的脚本测试：
   ```javascript
   toast("测试通知");
   ```
3. 保存 → 运行
4. 应该看到屏幕中央弹出"测试通知"
5. ✅ 跑通 = AutoX.js 基础工作正常

**如果没看到通知**：
- 检查通知权限
- 检查 AutoX.js 是不是被清理了
- 重启 AutoX.js 再试

---

## 第 5 步：测试 Tasker 定时触发

1. 打开 Tasker
2. 新建一个 Tasker 任务：
   - Tasks → + → 名字"test"
   - 加 Action: Misc → Flash → "Tasker 在跑"
3. 新建一个 Profile：
   - Profiles → + → Time → 选 1 分钟后
   - 关联到 "test" 任务
4. 等 1 分钟看会不会弹通知

**如果 1 分钟后没弹**：
- 90% 是上面 3.1-3.6 没配好
- 重新检查每项
