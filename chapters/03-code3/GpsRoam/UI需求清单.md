# GPS 漫游 · UI 需求清单（精简版）

> 需求已收窄为「**录一次真实轨迹 → 以后按它回放，回放中可实时调倍速**」。
> 本清单只覆盖这条主路径。上一版里为地图、画布、坐标输入设计的内容**全部作废**。

---

## 0. 一句话

UI 只需要把三件事做顺：**录一段 → 存下来 → 以后放**。

---

## 1. 设计原则（"简单轻量"的落地标准）

- **总共两个界面**：主屏 + 轨迹库。没有第三个。
- **主屏常驻元素 ≤ 4 个**：状态名、状态行、主控区、一个入口。
- **不用的东西直接不显示**，不是置灰 —— 置灰的按钮也是噪音。
- **任何时候只有一个主按钮**，而且它最大、位置固定。
- 不做导航栏、不做 tab、不做侧滑抽屉、不做设置页。
- 一屏装得下，不需要滚动。

---

## 2. 主屏

核心是一个**随状态切换的主控区**，位置固定不变 —— 这样按钮永远在同一个地方，闭着眼也能按。

### 2.0 屏幕组成（自上而下）

| 区域 | 说明 |
|---|---|
| 状态名 | 大字号，颜色随状态：空闲/已选＝灰、录制＝红、回放＝蓝、暂停＝黄 |
| 状态行 | 等宽字体，数值跳动时不左右抖 |
| 权限条 | **只在缺权限时出现**，两项齐了整条隐藏 |
| 轨迹预览 | 只读：起点绿、终点红、游标蓝；已走段实线、未走段虚线 |
| 倍速行 | 只在「已选轨迹 / 回放中 / 已暂停」出现 |
| 主按钮 | 位置最固定、尺寸最大（58dp） |
| 次按钮 | 见下表各状态 |
| 轨迹库入口 | 底部，带条数；跑着的时候禁用 |

### 2.1 空闲

| 元素 | 说明 |
|---|---|
| 状态名 | 空闲 |
| 状态行 | 未运行 |
| **主按钮** | 开始录制 |
| 次按钮 | 选择轨迹回放（轨迹库为空时隐藏） |
| 底部 | 轨迹库 N 条 |

### 2.1b 已选轨迹（从轨迹库选完回到主屏）

| 元素 | 说明 |
|---|---|
| 状态名 | 已选轨迹 |
| 状态行 | 名字 · 里程 · 时长 · 均速 |
| **主按钮** | 开始模拟 |
| 次按钮 | 换一条轨迹 |
| 倍速 | 这时就能先调好，回放中再改也一样生效 |

### 2.2 录制中

| 元素 | 说明 |
|---|---|
| 状态名 | 录制中 |
| 状态行 | 计时 + 已记点数（红色） |
| **主按钮** | 停止并保存（红色） |
| 次区 | 已走里程（只读） |
| 底部 | 可退出 App，后台继续录 |

### 2.3 回放中

| 元素 | 说明 |
|---|---|
| 状态名 | 回放中 |
| 状态行 | 已走百分比 / 里程 |
| **主按钮** | 暂停 |
| 次按钮 | 停止 |
| 倍速 | `1× 2× 5× 10×` 四选一，**点中即生效，不弹确认** |
| 底部 | 倍速改动即时生效 |

### 2.4 已暂停

状态行转黄，主按钮变「继续」，其余同上。

### 2.5 权限

**只在缺权限时出现**，一行字 + 一个按钮。权限齐了就完全不显示。

- 录制只需要「精确定位」权限
- 回放还需要「模拟位置」授权，提示里写清楚去哪开

---

## 3. 轨迹库

一个列表，每行只放三样信息。

- 行内容：**名字** / 点数 · 里程 · 时长
- 点行 = 载入并回主屏
- 长按 = 删除 / 重命名
- 空状态：一句话 + 一个「去录制」按钮

---

## 4. 必须覆盖的状态

| 状态 | 表现 |
|---|---|
| 缺权限 | 权限条：一行字 + 跳转按钮 |
| 空闲 · 无轨迹 | 隐藏「选择轨迹回放」 |
| 录制中 | 计时 + 点数，红色 |
| 录制 20 秒收不到定位 | 「还没收到定位，到空旷处试试」 |
| 停止录制 | 轻提示「已保存」；点数不足则提示重录 |
| 回放中 / 已暂停 | 状态色区分，按钮语义区分 |
| 回放完成 | 轻提示，回到空闲 |
| 应用重启 | 服务还在跑就恢复对应状态 |

就这些。**不再有**「空状态插画」「加载骨架屏」「错误详情展开」那一套。

---

## 5. 明确不做（本版砍掉的）

| 砍掉 | 原因 |
|---|---|
| 地图 / 画布绘制 | 对「复现真实路线」没用，录制才是主线 |
| 地图选点、十字准星、Follow/Free | 无地图，整块作废 |
| 坐标粘贴导入 | 同上，真需要时再加 |
| 手画路线库 | 只保留轨迹库一套，不要两套库 |
| 九宫格数据面板 | 精度 / 海拔 / 航向对使用者没意义，收成状态行一行 |
| 摇杆手动控制 | 与主路径无关 |
| 首次启动分步引导 | 退化为一条权限提示 |
| 设置页 | 现在没有值得设的东西 |
| 登录 / 云同步 / 分享 / 排行榜 | 不做 |

> 上一版原型 `ui-prototype/index.html` 里的**地图选点、绘制路径、摇杆、常驻通知、启动引导**等页面，
> **全部不在本版范围内**。原型保留作参考，但要按本清单重新收敛。

---

## 6. 交互细节

- 停止录制**不做二次确认**（要能快速停），但保存成功必须有明确反馈
- 倍速改动即时生效：不打断回放，不重置位置与已走距离
- 录制中退到后台继续录（前台服务 + 常驻通知），回 App 要能恢复显示
- 通知栏提供 暂停 / 继续、停止
- 所有点击热区 ≥ 48dp；主按钮 ≥ 56dp

---

## 7. 视觉

- 状态色**只有三种**：录制中 = 红、回放中 = 主色、暂停 = 黄
- 数字一律等宽字体，避免数值跳动时左右抖
- 一屏一个主色，不要多彩
- 大字号 + 大留白 + 少元素，比堆信息更像一个「轻量工具」
